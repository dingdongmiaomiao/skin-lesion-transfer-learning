# 基于迁移学习的皮肤病灶良恶性识别实验报告

## 一、项目背景与研究意义

皮肤癌，尤其是黑色素瘤，是一种具有较高危险性的皮肤恶性肿瘤。若能在早期通过皮肤镜图像发现疑似恶性病灶，可以为后续医学诊断和治疗争取更多时间。随着深度学习和医学影像分析的发展，卷积神经网络已经被广泛应用于图像分类、目标检测和辅助诊断等任务中。

本项目选择 ISIC 2020 / SIIM-ISIC Melanoma Classification 数据集作为实验对象，基于 PyTorch 框架和迁移学习方法，对皮肤镜图像进行良恶性二分类识别。分类目标为：

* `0`：良性病灶；
* `1`：恶性病灶。

本项目并不追求开发完整医学诊断系统，而是以课程大项目为目标，完整实现一个机器学习实验流程，包括数据处理、模型训练、调优实验、迁移学习微调、模型评估、可解释性分析和特征可视化。通过该项目，我们希望理解迁移学习在医学图像分类任务中的效果，并分析类别不平衡、模型微调策略和可解释性分析对实验结果的影响。

---

## 二、数据集与任务设置

### 2.1 数据集来源

本项目使用 ISIC 2020 / SIIM-ISIC Melanoma Classification 数据集。该数据集包含皮肤镜图像及其对应的良恶性标签，适合用于黑色素瘤识别相关实验。

本地数据结构如下：

```text
data/
└── ISIC_2020/
    ├── ground_truth.csv
    └── train/
        ├── ISIC_xxxxxxx.jpg
        ├── ISIC_xxxxxxx.jpg
        └── ...
```

其中 `ground_truth.csv` 至少包含两列：

* `image_name`：图像文件名，不含 `.jpg` 后缀；
* `target`：图像标签，`0` 表示良性，`1` 表示恶性。

### 2.2 数据划分方式

本项目在代码中使用 `train_test_split` 进行训练集与验证集划分，比例为：

```text
训练集：80%
验证集：20%
```

划分时采用分层抽样，尽量保证训练集和验证集中良性、恶性样本比例一致。

### 2.3 类别不平衡问题

该数据集存在明显类别不平衡问题，良性样本数量远多于恶性样本。在最终验证集中，样本分布为：

| 类别           |   数量 |
| ------------ | ---: |
| 良性 Benign    | 6509 |
| 恶性 Malignant |  117 |

恶性样本仅占验证集约 1.77%。因此，本项目没有单纯使用 Accuracy 作为主要指标，而是重点关注 AUC、Recall / Sensitivity、Specificity 和混淆矩阵结果。

在训练过程中，本项目使用 `BCEWithLogitsLoss`，并通过 `pos_weight` 增大恶性样本在损失函数中的权重，以缓解类别不平衡带来的影响。

## 三、方法与技术路线

### 3.1 总体流程

本项目整体实验流程如下：

```text
数据读取与预处理
        ↓
Baseline 模型训练
        ↓
优化器与学习率调度器对比
        ↓
迁移学习微调策略对比
        ↓
最终模型评估
        ↓
ROC、混淆矩阵、Grad-CAM、t-SNE 可视化分析
        ↓
实验报告与项目展示
```

### 3.2 模型选择

本项目主要使用 ResNet-18 作为基础模型。ResNet-18 结构相对轻量，适合在普通 GPU 环境下训练，同时可以加载 ImageNet 预训练权重，用于迁移学习实验。

模型最后的分类层被替换为单输出节点，用于二分类任务。模型输出为一个 logit，训练时使用 `BCEWithLogitsLoss`，预测时通过 sigmoid 转换为恶性概率。

### 3.3 图像预处理与数据增强

训练集图像采用以下处理方式：

* 随机裁剪；
* 随机水平翻转；
* 随机垂直翻转；
* 随机旋转；
* 颜色扰动；
* ImageNet 均值和标准差归一化。

验证集图像不使用随机增强，仅进行 Resize、CenterCrop 和标准化处理。

### 3.4 迁移学习策略

本项目比较了三种迁移学习方式：

1. 仅训练分类头；
2. 解冻最后 10 层；
3. 全模型微调。

其中，仅训练分类头用于构建 baseline；后两种用于观察解冻更多网络参数后模型性能是否提升。

在微调阶段，本项目使用差异化学习率：

```text
backbone_lr = 1e-5
head_lr = 1e-4
```

这样做的原因是：预训练 backbone 已经学习到通用视觉特征，学习率不宜过大；而最后的分类头是针对当前任务重新训练的，因此可以使用相对更高的学习率。

## 四、实验设计

### 4.1 Baseline 实验

Baseline 实验使用 ImageNet 预训练 ResNet-18，冻结 backbone，仅训练最后的分类头。

主要参数如下：

| 参数         | 设置                                |
| ---------- | --------------------------------- |
| Model      | ResNet-18                         |
| Pretrain   | ImageNet                          |
| Epochs     | 15                                |
| Batch Size | 16                                |
| Image Size | 224                               |
| Optimizer  | Adam                              |
| Scheduler  | ReduceLROnPlateau                 |
| Loss       | BCEWithLogitsLoss with pos_weight |
| Metric     | Validation AUC                    |

Baseline 实验的主要作用是建立后续对比实验的基准。

---

### 4.2 优化器与学习率调度器对比实验

在 baseline 基础上，本项目进一步比较不同优化器和学习率调度策略的影响。

为保证实验公平，本阶段固定以下条件：

* 模型均为 ResNet-18；
* 均加载 ImageNet 预训练权重；
* 均冻结 backbone；
* 均只训练最后分类头；
* 均训练 15 个 epoch；
* 评价指标均为验证集 AUC。

本阶段共运行 5 组实验：

| 实验组           | Optimizer      | Scheduler         |
| ------------- | -------------- | ----------------- |
| adam_plateau  | Adam           | ReduceLROnPlateau |
| adamw_plateau | AdamW          | ReduceLROnPlateau |
| sgd_plateau   | SGD + momentum | ReduceLROnPlateau |
| adam_fixed    | Adam           | Fixed LR          |
| adam_cosine   | Adam           | CosineAnnealingLR |

---

### 4.3 微调策略对比实验

在完成调优实验后，本项目选择 `AdamW + ReduceLROnPlateau` 作为后续微调实验的默认训练策略，并进一步比较不同微调方式。

实验包括：

| 策略        | 说明                     |
| --------- | ---------------------- |
| 仅训练分类头    | 冻结 backbone，仅训练最后分类层   |
| 解冻最后 10 层 | 解冻 backbone 后部部分参数和分类头 |
| 全模型微调     | 解冻全部网络参数               |

该实验用于分析 ISIC 皮肤镜图像任务是否需要对 ImageNet 预训练特征进行更充分的领域适应。

---

### 4.4 最终模型评估

最终模型选择微调实验中表现最好的 full_finetune 最佳模型。评估内容包括：

* ROC 曲线；
* AUC；
* Accuracy；
* Precision；
* Recall / Sensitivity；
* Specificity；
* F1；
* 混淆矩阵；
* 默认阈值 0.5 与 Youden 阈值对比。

### 4.5 可解释性与特征可视化

为了进一步分析模型行为，本项目进行了两类可视化：

1. **Grad-CAM 可解释性分析**
   用于观察模型在判断恶性类别时主要关注的图像区域。

2. **t-SNE 特征可视化**
   用于观察最终模型分类头前一层特征在二维空间中的分布情况。

## 五、实验结果与分析

### 5.1 Baseline 实验结果

Baseline 使用 ResNet-18，仅训练分类头，最终取得：

| 模型        | 策略                 | Best AUC |
| --------- | ------------------ | -------: |
| ResNet-18 | 冻结 backbone，仅训练分类头 |  0.83784 |

Baseline 的 AUC 从初始阶段逐渐提升到约 0.838，说明 ImageNet 预训练特征对于皮肤镜图像良恶性识别具有一定迁移能力。尽管皮肤镜图像与自然图像存在差异，但预训练模型仍能提取部分有用的底层和中层视觉特征。

---

### 5.2 优化器与学习率调度器实验结果

调优实验结果如下：

| 实验组           | Optimizer      | Scheduler         | Best AUC | Best Epoch |
| ------------- | -------------- | ----------------- | -------: | ---------: |
| adam_plateau  | Adam           | ReduceLROnPlateau | 0.837860 |         15 |
| adamw_plateau | AdamW          | ReduceLROnPlateau | 0.837864 |         15 |
| sgd_plateau   | SGD + momentum | ReduceLROnPlateau | 0.822258 |         15 |
| adam_fixed    | Adam           | Fixed LR          | 0.837980 |         13 |
| adam_cosine   | Adam           | CosineAnnealingLR | 0.835348 |         13 |

从结果可以看出，Adam 和 AdamW 表现几乎一致，Best AUC 均约为 0.838；SGD + momentum 的表现明显低于 Adam 系列优化器，说明在当前冻结 backbone、只训练分类头的设置下，自适应优化器具有更好的收敛效果。

在学习率调度方面，Fixed LR 与 ReduceLROnPlateau 的表现非常接近，CosineAnnealingLR 略低。虽然 Fixed LR 的数值最高，但差距极小。考虑到后续微调实验中可训练参数增加，训练过程可能更容易波动，因此本项目后续采用 AdamW + ReduceLROnPlateau 作为默认训练策略。

---

### 5.3 微调策略实验结果

微调策略实验结果如下：

| 微调策略      | Best AUC | Best Epoch |     可训练参数量 |
| --------- | -------: | ---------: | ---------: |
| 仅训练分类头    | 0.837864 |         15 |         较少 |
| 解冻最后 10 层 | 0.855562 |         15 |  4,853,761 |
| 全模型微调     | 0.885590 |          7 | 11,177,025 |

可以看到，随着可训练层数增加，模型性能明显提升。解冻最后 10 层后，Best AUC 从约 0.838 提升到 0.856；全模型微调进一步提升到 0.886。

相比仅训练分类头，全模型微调带来的 AUC 提升约为：

```text
0.885590 - 0.837864 = 0.047726
```

这说明在 ISIC 皮肤镜图像分类任务中，仅依赖 ImageNet 预训练特征仍然存在局限。皮肤镜图像与自然图像在纹理、颜色分布、成像方式和判别区域上存在明显差异，因此解冻更多网络层可以使模型更充分地适应医学图像领域特征。

不过，全模型微调在第 7 个 epoch 达到最佳 AUC，后续验证 Loss 出现一定波动，说明全模型微调虽然提高了模型上限，但也带来了更高的过拟合风险。因此，本项目最终选择第 7 个 epoch 保存的 full_finetune 最佳模型作为最终模型。

---

### 5.4 最终模型评估结果

最终模型在验证集上的 ROC-AUC 为：

```text
AUC = 0.885581
```

这与微调实验中记录的最佳 AUC 基本一致，说明最终评估脚本与训练过程结果一致。

#### 默认阈值 0.5

| 指标                   |       数值 |
| -------------------- | -------: |
| AUC                  | 0.885581 |
| Accuracy             | 0.812406 |
| Precision            | 0.068913 |
| Recall / Sensitivity | 0.769231 |
| Specificity          | 0.813182 |
| F1                   | 0.126493 |
| TN                   |     5293 |
| FP                   |     1216 |
| FN                   |       27 |
| TP                   |       90 |

在默认阈值 0.5 下，模型识别出 117 个恶性样本中的 90 个，恶性召回率为 76.92%。同时，模型将 1216 个良性样本误判为恶性，因此 Precision 较低。

#### Youden 阈值

Youden 阈值为：

```text
0.383211
```

在该阈值下，评估结果如下：

| 指标                   |       数值 |
| -------------------- | -------: |
| AUC                  | 0.885581 |
| Accuracy             | 0.758980 |
| Precision            | 0.060570 |
| Recall / Sensitivity | 0.871795 |
| Specificity          | 0.756952 |
| F1                   | 0.113270 |
| TN                   |     4927 |
| FP                   |     1582 |
| FN                   |       15 |
| TP                   |      102 |

使用 Youden 阈值后，模型恶性召回率由 76.92% 提升至 87.18%，漏诊数由 27 降低至 15。代价是误报良性样本数量增加，Accuracy 和 Specificity 下降。

对于黑色素瘤筛查任务而言，漏诊恶性病灶的风险通常高于误报，因此提高 Recall / Sensitivity 具有一定实际意义。但误报过多也会增加后续人工复核压力，说明模型仍需要进一步优化。

### 5.5 Grad-CAM 可解释性分析

本项目使用 Grad-CAM 对最终模型进行可解释性分析，并分别选取以下四类样本：

1. TP：真实恶性，预测恶性；
2. FN：真实恶性，预测良性；
3. FP：真实良性，预测恶性；
4. TN：真实良性，预测良性。

分析结果表明，对于预测正确的恶性样本，模型热力区域通常集中在病灶主体或周围异常纹理区域，说明模型能够在一定程度上关注与恶性判别相关的视觉区域。

对于漏诊的恶性样本，热力图有时集中在图像边缘或背景区域，而没有覆盖病灶主体。这说明模型在部分困难恶性样本上未能有效捕捉关键病灶特征，是后续改进的重要方向。

对于误报为恶性的良性样本，热力图通常集中在颜色较深、边界复杂或纹理变化明显的区域。这说明模型可能将部分良性病灶中的复杂色素表现误认为恶性特征，从而导致假阳性数量较多。

总体来看，Grad-CAM 结果说明模型具有一定可解释性，但误报和漏诊样本也提示模型仍可能受到颜色、纹理、边缘区域等因素影响。

### 5.6 t-SNE 特征可视化分析

本项目提取最终模型分类头前一层特征，并使用 PCA + t-SNE 进行二维可视化。

整体抽样验证集包含：

| 类别 |   数量 |
| -- | ---: |
| 良性 | 2383 |

由于良性样本远多于恶性样本，整体 t-SNE 图中良性样本占主导，恶性样本虽然在部分区域有一定聚集，但整体仍与良性样本存在明显重叠。

为了更清楚地观察两类特征分布，本项目进一步进行了类别平衡抽样：

| 类别 |  数量 |
| -- | --: |
| 良性 | 100 |
| 恶性 | 100 |

在平衡抽样图中，恶性样本与良性样本呈现一定分离趋势，但仍存在交叠。这说明最终模型提取到了一定判别性特征，但皮肤病灶良恶性分类仍然具有较高难度，部分良性和恶性样本在视觉特征上较为相似。

## 七、遇到的问题与解决方法

### 7.1 计算资源限制

本项目训练深度学习模型需要一定 GPU 资源，而组内成员电脑性能存在差异。因此项目采用分工协作方式：一名成员主要负责实验设计、文档整理和结果分析；另一名成员主要负责代码运行和模型训练。

这种分工既提高了项目推进效率，也保证了实验结果能够在有限时间内完成。

### 7.2 类别不平衡问题

ISIC 数据集中恶性样本数量远少于良性样本，导致 Accuracy 和 Precision 容易受到类别分布影响。为此，本项目采用以下策略：

1. 训练时使用 `pos_weight` 增加恶性样本损失权重；
2. 评估时重点关注 AUC、Recall / Sensitivity 和 Specificity；
3. 使用 Youden 阈值分析召回率和误报之间的权衡；
4. 使用混淆矩阵直观展示模型分类结果。

### 7.3 微调过程中的过拟合风险

全模型微调显著提高了 AUC，但训练后期验证 Loss 出现波动。这说明随着可训练参数量增加，模型更容易出现过拟合风险。

本项目通过保存最佳验证 AUC 对应模型来避免使用过拟合较明显的最后一轮模型。最终模型采用 full_finetune 第 7 个 epoch 保存的 best model。

### 7.4 可解释性结果不完全理想

Grad-CAM 分析显示，部分漏诊样本的热力区域偏离病灶主体。这说明模型并非在所有样本上都能稳定关注关键病灶区域。后续可以考虑加入病灶分割、注意力机制或更强的数据增强策略，提高模型对关键区域的关注能力。

## 八、项目不足与改进方向

尽管本项目完成了较完整的实验流程，但仍存在一些不足。

### 8.1 缺少独立测试集评估

本项目主要使用训练集划分出的验证集进行评估，没有使用独立测试集。因此当前结果只能说明模型在验证集上的表现，不能直接代表其真实泛化能力。后续可进一步引入独立测试集进行更严格评估。

### 8.2 消融实验仍可进一步扩展

由于时间和计算资源限制，本项目没有继续完成 Mixup、CutMix、标签平滑、Dropout 等数据增强与正则化消融实验。后续可以进一步比较这些方法对模型泛化能力的影响。

### 8.3 模型结构仍较基础

本项目主要使用 ResNet-18。虽然 ResNet-18 训练成本较低，但模型表达能力有限。后续可以尝试 EfficientNet、ConvNeXt、Swin Transformer 等更强模型，并比较其在医学图像分类任务中的表现。

### 8.4 类别不平衡仍然明显影响结果

尽管本项目使用了 `pos_weight`，最终模型 Precision 仍然较低。后续可以考虑：

* 重采样策略；
* Focal Loss；
* 更合理的阈值选择；
* 基于 PR-AUC 的评估；
* 引入更多恶性样本；
* 多模型集成。

### 8.5 可解释性分析可进一步增强

当前 Grad-CAM 只能提供粗粒度热力区域。后续可以结合医生标注、病灶分割掩膜或更精细的注意力可视化方法，进一步验证模型是否真正关注医学上有意义的区域。

本项目围绕皮肤病灶良恶性识别任务，基于 ISIC 数据集和 PyTorch 框架，完成了一个较完整的机器学习实验项目。

实验结果表明：

1. ImageNet 预训练 ResNet-18 在皮肤镜图像分类任务中具有较好的迁移能力；
2. Adam 和 AdamW 优化器明显优于 SGD + momentum；
3. 全模型微调显著优于仅训练分类头和解冻最后 10 层；
4. 最终模型在验证集上取得约 0.886 的 ROC-AUC；
5. 使用 Youden 阈值可以提升恶性样本召回率，但会增加误报；
6. Grad-CAM 显示模型在部分恶性样本上能够关注病灶相关区域；
7. t-SNE 显示模型提取的深度特征具有一定类别区分能力，但良恶性样本仍存在重叠。

总体而言，本项目不仅完成了模型训练，还通过调优实验、微调策略比较、混淆矩阵、ROC 曲线、Grad-CAM 和 t-SNE 对模型性能与行为进行了较系统的分析。虽然模型仍存在误报、漏诊和类别不平衡影响等问题，但作为课程大项目，本项目较完整地展示了迁移学习在医学图像分类任务中的应用流程和实验分析方法。
